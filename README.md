# 🪰 FruitFlyBrain — *Drosophila* connectome datasets & projects

An organized, self-contained workspace built around **officially released fruit
fly (*Drosophila melanogaster*) brain connectome data**, with four working,
runnable projects that analyze and simulate the fly brain.

Everything here comes from reputable primary sources (Janelia HHMI and the
Princeton/MRC FlyWire consortium), was downloaded with **no login required**,
and has been **run end-to-end** — every project's `outputs/` folder was
generated by the code in this repo.

```
FruitFlyBrain/
├── README.md                     ← you are here
├── requirements.txt              ← Python deps
├── .venv/                        ← virtual environment (created during setup)
├── datasets/
│   ├── README.md                 ← provenance, licenses, citations, checksums
│   ├── hemibrain/                ← Janelia FlyEM hemibrain v1.2 (full connectivity)
│   └── flywire_fafb/             ← Princeton FlyWire whole-brain annotations
└── projects/
    ├── _common.py                ← shared dataset-path helpers
    ├── 01_connectome_graph_analysis/   ← network science on the connectome
    ├── 02_neurotransmitter_atlas/      ← whole-brain neuron & NT census
    ├── 03_shortest_path_circuits/      ← trace strongest signal pathways
    ├── 04_connectome_neural_network/   ← simulate activity on real wiring
    └── 05_navis_3d_viewer/             ← render neuron shapes in interactive 3D
```

## The data (see `datasets/README.md` for full details)

| Dataset | What it is | Scale | Source |
|---|---|---|---|
| **hemibrain v1.2** | dense reconstruction of the central brain — every traced neuron + synapse | 21,739 neurons · 3.55 M connections · 14.3 M synapses | Janelia FlyEM (CC BY 4.0) |
| **FlyWire FAFB** | annotations for a *complete* adult brain | 139,248 neurons · 8,840 cell types | FlyWire consortium (CC BY 4.0) |

## Quick start

```bash
# from the FruitFlyBrain/ directory
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt        # Windows
# source .venv/bin/activate && pip install -r requirements.txt   # macOS/Linux

python download_datasets.py          # fetch the connectome data (~275 MB, first run only)

.venv\Scripts\python projects\01_connectome_graph_analysis\analyze.py
.venv\Scripts\python projects\02_neurotransmitter_atlas\atlas.py
.venv\Scripts\python projects\03_shortest_path_circuits\trace.py
.venv\Scripts\python projects\04_connectome_neural_network\simulate.py
.venv\Scripts\python projects\05_navis_3d_viewer\view_neurons.py
```

Each script writes figures and CSV tables into its own `outputs/` folder and
prints a summary to the console.

## The projects

| # | Project | Dataset | Highlight of the (real) output |
|---|---------|---------|-------------------------------|
| 1 | **Connectome graph analysis** | hemibrain | Heavy-tailed degree distribution; top hubs = **APL** & **DPM** |
| 2 | **Neurotransmitter atlas** | FlyWire | Whole brain is **~62% cholinergic**, 18% glutamate, 14% GABA |
| 3 | **Synaptic pathway tracer** | hemibrain | Strongest **KC→MBON** learning route (+ APL/DPM detour) |
| 4 | **Connectome-constrained NN** | hemibrain | Stimulating **ER** ring neurons drives the **EPG** compass |
| 5 | **3D neuron viewer (NAVis)** | hemibrain | Interactive 3D neuron shapes → rotatable `neurons_3d.html` |

Each project folder has its own `README.md` with usage, options and a sanity
check that confirms the result matches known fly neuroscience.
