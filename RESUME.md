# Résumé bullets — FruitFlyBrain

Paste-ready lines describing this project. All numbers are real, reproduced by

## One-line project title
**Fruit-Fly Connectome ML** — analyzed, embedded and modeled a complete
*Drosophila* brain connectome (3.5 M synapses) with 8 reproducible Python
projects spanning network science, unsupervised learning, and graph ML.

## Résumé bullets (pick 2–4)

- Built **FlyLab**, an interactive embodied-AI system where plain-English
  commands train neural-network brains that then control **NeuroMechFly v2**
  (a micro-CT-based *Drosophila* body) in **MuJoCo physics**. The physics fly
  succeeded on **7 of 9** commanded tasks, including chemotaxis and phototaxis.
- Engineered **sim-to-sim transfer**: calibrated a fast surrogate against 49
  physics drive conditions, then diagnosed and fixed transfer failures with
  **domain randomization using measured gait wobble**, sensory integration and
  **common-random-number** Evolution Strategies (physics success **67% → 86%**).
- Diagnosed **catastrophic forgetting** in a shared multi-task network (57%
  physics success after a 9-lesson curriculum) and replaced it with **per-skill
  brains trained continuously with physics-in-the-loop validation**,
  keep-the-best selection and held-out physics tests.
- Profiled and optimized a MuJoCo control loop **~20× faster** (controller
  sub-stepping at 1 kHz with verified gait fidelity).

- Built a **connectivity-based cell-type classifier** (RandomForest + neural
  net) predicting neuron identity across **53 cell-type families** from synaptic
  fingerprints, reaching **88% accuracy / 0.85 macro-F1** vs. an 11% baseline.
- Learned **128-dimensional neuron embeddings** from a 3.5 M-edge connectome via
  truncated-SVD and recovered known cell types **without labels** (NMI 0.59,
  63% mean cluster purity), visualized with t-SNE.
- Engineered a **leakage-free synapse link-prediction** pipeline (held-out edge
  split, graph embeddings, gradient boosting) achieving **0.97 ROC-AUC / 0.97
  PR-AUC** on unseen connections.
- Performed **network-science analysis** of the connectome (degree
  distributions, hub detection, connected components), correctly surfacing the
  brain's known giant hub neurons (APL, DPM).
- Simulated **connectome-constrained recurrent dynamics** on the fly's central
  complex, reproducing the ER→EPG "compass" pathway from raw synaptic weights.
- Traced **strongest multi-synapse circuits** (weighted shortest paths) and
  rendered **interactive 3-D neuron morphologies** with NAVis/Plotly.
- Packaged everything reproducibly: virtual-env + `requirements.txt`, one-command
  dataset downloader, per-project docs, MIT license and citation metadata.

## Talking points (for interviews)
- **Why it's real:** every metric is regenerated by scripts on primary
  peer-reviewed datasets (Nature / eLife), not a toy dataset.
- **Leakage awareness:** the link-prediction model learns embeddings only from
  the training graph and is scored on edges it never saw — a common trap avoided.
- **Domain grounding:** results were validated against known fly neuroscience
  (APL/DPM hubs, KC→MBON learning circuit, ER→EPG compass), showing the pipeline
  measures real biology, not artifacts.
